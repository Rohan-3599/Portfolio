# Rohan Sinha — Portfolio

Static portfolio built with HTML/CSS/JS. Featured case studies are based on USC computer graphics and deep-learning projects.

## Run locally
Open `index.html` directly, or run a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy with GitHub Pages
In the repository: Settings → Pages → Deploy from a branch → `main` / root.

## Assets
The project images in `assets/` were generated from the supplied final project reports. Replace them later with original screenshots/renders if you have higher-resolution source images.
